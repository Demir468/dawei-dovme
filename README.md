# Dawei'yi Dövme — Klasik Flash Stres Atma Oyunu

2000'lerin klasik Türk Flash stres atma oyunlarından esinlenen, hem **bilgisayardan** hem de **mobilden (iOS / Android)** tarayıcı üzerinden anında oynanabilen HTML5 oyun.

🎮 **Hemen Oyna:** [https://demir468.github.io/dawei-dovme/](https://demir468.github.io/dawei-dovme/)

## Özellikler
- **5 Farklı Saldırı**: 👊 Yumruk, 🖐️ Tokat, 🦶 Tekme, 🍅 Çürük Domates ve 🩴 Anne Terliği (+ ⚡ **50/50 İntikamı** Ulti Kombo).
- **Gerçek Zamanlı 2D Yüz & Vücut Deformasyonu**: Darbe anında esneyen yay fiziği; hasar arttıkça sırıtan yüz ifadesinin şişmiş, yamulmuş bir acı ifadesine dönüşmesi.
- **Kademeli Hasar Görselleri**: Göz morarması, burun ve kaş kanaması, kırılıp uçan dişler, el/terlik/bot izleri ve alında kanlı yara bandı.
- **Ses Efektleri & Adamın Sesi**: Web Audio API ile üretilen darbe efektleri, acı/inleme ses sentezi ve mobilde titreşim desteği.
